# App: Quality Control (QA)

## Descrição
Controla a validação final das Ordens de Serviço antes do encerramento oficial.

## Principais Funcionalidades
- Processo de validação e aprovação de Ordens de Serviço
- Retorno de Ordens de Serviço para o técnico para ajustes
- Registro de histórico de validações
- Interface de checklist de validação para os usuários com Permissão de Controle Total
