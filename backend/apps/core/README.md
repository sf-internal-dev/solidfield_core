# App: Core

## Descrição
Responsável por toda a base estrutural do projeto SolidField. Inclui:

- Sistema de usuários
- Níveis de permissão
- Autenticação e autorização
- Controle de login e histórico de acesso (IP, device, horário)
- Reset de senha, bloqueio de contas
- Criação e gestão de contas da empresa (Conta Vigente)

## Principais Funcionalidades
- Custom User Model
- Controle de Permissões por nível
- Sistema de autenticação JWT
- Histórico de Login por usuário
