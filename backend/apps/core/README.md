# App: Core

## Description
Responsible for the foundational infrastructure of the SolidField project. This app centralizes the management of user accounts, authentication, authorization, and organizational control. It includes:

- User management system
- Role-based permission levels (L1, L2, L3...)
- Authentication and access control
- Login tracking (IP, device, timestamp)
- Password reset and account lockout
- Company account creation and management (Active Account context)

## Key Features
- Custom Django User Model

- Permission management by role level

- JWT-based authentication system

- Login history and access logs per user

- Account status management (active, locked, password reset)

- Support for multi-tenant user separation via organizational accounts
