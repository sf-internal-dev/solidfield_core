# App: Mobile Sync

## Descrição
API exclusiva para consumo pelo aplicativo mobile (Capacitor).

## Principais Funcionalidades
- Autenticação de usuários via API
- Solicitação de Ordens de Serviço
- Upload de fotos
- Upload de checklists preenchidos
- Atualização de status via mobile
- Fila de sincronização offline
- Retorno de erros de sync (para log de problemas operacionais)

## Observação
Toda comunicação com o app mobile será RESTful com endpoints versionados.
