# App: Panel

## Descrição
Responsável por todos os indicadores e painéis gerenciais do SolidField.

## Principais Funcionalidades
- Total de Ordens de Serviço por período
- Taxa de conclusão no prazo
- Retrabalho por técnico
- Avaliação média de clientes
- Ordens com não-conformidades
- Fila de sincronização offline
- Log de atividades (Linha do Tempo Operacional)

## Observação
Este app será integrado visualmente com os Django Templates e acessado apenas por usuários L2 e L3.
