# App: Reporting

## Descrição
Responsável pela geração de relatórios exportáveis, PDFs de Ordens de Serviço e Listas de Verificações preenchidas.

## Principais Funcionalidades
- Exportação de Ordens de Serviço em PDF
- Exportação de Checklists preenchidos
- Exportação de histórico de atividades
- Integração futura com APIs de envio de documentos (ex: e-mail, whatsapp business api, etc)

## Observação
Este app será usado principalmente por usuários com Permissão de Controle Total.
